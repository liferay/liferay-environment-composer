# Wiki sources

Every file here is published to the [GitHub wiki](https://github.com/liferay/liferay-environment-composer/wiki) by `.github/workflows/sync-wiki.yaml` when it changes on `master`. Edit these files, not the wiki.

- One file per page. The filename is the title: `Saving-and-Sharing-Data.md` becomes "Saving and Sharing Data".
- `_Sidebar.md` and `_Footer.md` appear on every page. Add new pages to `_Sidebar.md` and the table in `Home.md`.
- Link between pages with the page name and no extension: `[Database Service](Database-Service#import-a-database-dump)`.
- When a PR adds or changes a feature, update the matching page in the same PR.
